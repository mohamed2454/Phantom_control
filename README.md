# Phantom Bot - خادم البوت والموقع المتكامل

## 🚀 التثبيت السريع على Railway

### الخطوة 1: انسخ الرابط
```
https://github.com/mohamed2454/Phantom_control
```

### الخطوة 2: اذهب إلى Railway
1. افتح [Railway.app](https://railway.app)
2. اضغط **Deploy Now**
3. اختر **GitHub**
4. ربط حسابك وحدد المستودع

### الخطوة 3: أضف المتغيرات
في لوحة Railway اضغط **Variables** وأضف:
```
DISCORD_TOKEN=your_token_here
FLASK_HOST=0.0.0.0
FLASK_PORT=8080
```

### الخطوة 4: Deploy! 🎉
سيعطيك رابط مثل:
```
https://phantom-bot-production.up.railway.app
```
